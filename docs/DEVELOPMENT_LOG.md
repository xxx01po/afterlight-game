# Журнал разработки

## 2026-11-03 — вертикальный срез главы 1
**Среда.** Пустой репозиторий `xxx01po/afterlight-game` (только README). Node 22, npm 10. GitHub-доступ есть (push в ветку). Vercel недоступен из контейнера (нет токена) → выбран GitHub Pages через Actions.

**Решения.**
- Чистый Three.js вместо R3F — полный контроль цикла и производительности; React только для UI.
- Всё процедурное (текстуры, звук) — нет ассетов, нет лицензионных рисков, лёгкая загрузка.
- «Мир как функция состояния» + очередь «изменений за спиной» → изменения реальности воспроизводимы и сохраняемы.
- Синтез «речи за дверью» вместо TTS: TTS звучит роботизированно и не проходит через фильтры Web Audio.

**Сделано.** Движок, ввод, игрок, коллизии; квартира, подъезд, лифт, кв. 48, двор с дождём; зеркало с запаздывающим отражением; ТВ с «живой камерой»; глазок; телефон (5 приложений); диалоговая система; режиссёр битов; 2 концовки; сохранения; настройки; титульный, пауза, финал; документация; CI и деплой.

**Найдено и исправлено в ходе проверки.**
- Зеркало, выключатели, домофон, календарь оказались внутри стен (стены 12 см по осевой линии) — сдвинуты на поверхность.
- Слишком синяя картинка — ослаблена холодная тонировка теней, нейтральнее заполняющий свет.
- 470 draw calls в широком ракурсе → склейка статики и разрезка многоматериальных стен → ~180.
- `Director.since()` возвращал `Infinity` для несостоявшихся событий → цепочка этапа 2 срабатывала без пауз. Теперь `-Infinity` (+ модульный тест).
- Записка меняла текст только на этапе 2 — теперь и позже.
- Бесконечный ре-рендер на финальном экране (селектор Zustand возвращал новый массив).
- Нельзя было открыть дверь сразу — добавлен импульсивный вариант.
- Снимок в режиме осмотра не помещался по высоте на iPhone.
