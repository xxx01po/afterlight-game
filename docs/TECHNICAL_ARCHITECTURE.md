# Техническая архитектура

**Стек:** TypeScript 5.9, React 19 (только интерфейс), Three.js r187 (рендер), Zustand 5 (состояние), Web Audio API (звук), Vite 8, Vitest.

React Three Fiber **не используется** сознательно: игровой цикл, порядок обновлений (ввод → игрок → сюжет → звук → рендер), склейка геометрии и рендер в отдельные цели проще и дешевле контролировать вручную. React не перерисовывается каждый кадр — UI подписан на сторы точечно.

## Структура
```
src/
  app/App.tsx                 экраны: титул / игра / финал
  game/
    Game.ts                   корень композиции сессии и «глаголы» для сценария
    core/Engine.ts            рендерер, цикл, адаптивное качество, timeScale (тесты)
    core/PostFX.ts            один полноэкранный проход: тонмаппинг, грейдинг, виньетка, зерно, глазок
    core/Input.ts             тач-джойстик, свайп-обзор, клавиатура/мышь
    player/Player.ts          FPS-контроллер, покачивание, шаги, скриптовый взгляд
    player/collision.ts       круг vs AABB (чистая функция, покрыта тестами)
    world/                    процедурная геометрия: builder, apartment, landing, outside,
                              textures (canvas), materials, Door, lights, Mirror, mergeStatic
    interactions/             луч из центра + реестр интерактивных объектов
    narrative/Director.ts     планировщик «битов» сюжета
    dialogue/                 типы и DialogueRunner (чистая state machine)
    audio/                    AudioEngine (шины, панорамирование), synth (процедурные звуки),
                              Soundscape (петли), occlusion (граф комнат)
    state/                    story (сохраняемое), ui, settings
    save/SaveSystem.ts        версионированный слот в LocalStorage
  scenes/chapter-01/          контент главы: beats, interactables, worldView, texts
  data/chapter01/             начальное состояние, диалог, список фрагментов
  ui/                         React-компоненты HUD, телефон, диалог, пауза, финал
```

## Ключевые решения
- **Мир = f(состояние).** Всё, что меняется в квартире, хранится в `story.world` (свет, двери, предметы, ТВ, лифт…). `worldView.applyWorld()` выставляет сцену по состоянию. Загрузка сохранения = применение состояния, без «переигрывания» событий.
- **Изменения «за спиной».** `queueUnseen(key, value, pos)` — изменение применяется, только когда точка вне конуса обзора или в другой комнате ≥0.6 с. Очередь сохраняется.
- **Бит-режиссёр.** Глава — список битов `{id, stage, when(), run()}`; `run` может быть async и использовать `wait()` по игровому времени (останавливается на паузе). Сработавшие биты попадают в сохранение. Случайностей в сюжете нет; фоновые звуки используют детерминированный ГПСЧ.
- **Звук.** Каждая позиционная эмиссия: фильтр низких частот → усиление → PannerNode. Граф комнат (двери, стены, окна, потолок) даёт срез частот и громкость самого «громкого» пути; открытая дверь меняет звучание в реальном времени.
- **Производительность.** Статическая геометрия склеивается по материалам (≈315 мешей → ≈40; стены с 6 материалами режутся по граням). Фиксированное число источников света (меняется только интенсивность — без перекомпиляции шейдеров). Тени — «пятна» вместо shadow map. Зеркало (Reflector) рендерится через кадр и только когда игрок рядом. Пресеты качества: pixel ratio 1/1.5/2, MSAA только на «Высоком», разрешение зеркала 0/256/512. Автоснижение при FPS < 27.
- **iOS.** AudioContext создаётся по нажатию «Начать»; `navigator.audioSession.type = 'playback'` (iOS 17+); пауза и `AudioContext.suspend()` при уходе вкладки в фон; блокировка жестов масштабирования; safe-area через `env()`.

## Как добавить главу
1. `data/chapterNN/initialState.ts` (+ перенос результата прошлой главы из `afterlight.ch1.result`).
2. `scenes/chapter-NN/{beats,interactables,worldView,index}.ts` → `ChapterModule`.
3. Новые локации — функции в `game/world/*` с `WorldBuilder`.
4. Диалоги — данные `Dialogue` в `data/`.
