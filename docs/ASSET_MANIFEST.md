# Asset Manifest

Демо не содержит внешних медиафайлов. Всё генерируется кодом при запуске — это сокращает вес (≈270 КБ gzip JS) и снимает вопросы лицензий.

| Тип | Что | Где создаётся | Примечание |
|---|---|---|---|
| Геометрия | Квартира, мебель, подъезд, лифт, кв. 48, двор | `src/game/world/apartment.ts`, `landing.ts`, `outside.ts` | примитивы Three.js, склейка статики |
| Текстуры | обои ×2, краска кухни, плитка ×2, линолеум «ёлочкой», ламинат, потолок с подтёком, подъезд, мозаика, дерматин, крашеная дверь, ДСП ×2, ткани, ковёр, панель лифта, фасады | `src/game/world/textures.ts` (Canvas 2D) | 256–1024 px, сид-ГПСЧ |
| Экраны | часы микроволновки, ТВ (перерыв / помехи / «живая» камера), табло лифта | `CanvasScreen.ts`, `scenes/chapter-01/index.ts` | |
| Фото/бумаги | фото в телефоне ×6, фото на полке и оборот, полароид ×2, листовка, календарь, таблички | `src/ui/painters.ts`, `apartment.ts`, `landing.ts` | |
| Шейдеры | дождь (линии), капли на стекле, постобработка | `outside.ts`, `core/PostFX.ts` | |
| Звук | дождь, тон комнаты, холодильник, вентиляция, ТВ, кран, чайник, гул лампы, стуки, шаги ×5 покрытий, скрип, щеколда, хлопок, ящик, бумага, удары за стеной, волочение, трубы, бульканье, машина, лифт, двери лифта, домофон, вибрация, рингтон, сигналы, «речь за дверью», дыхание, дрон, стинг, финальный мотив | `src/game/audio/synth.ts`, `Soundscape.ts` | **полностью синтезированы** Web Audio API; это не записанная фонограмма. Голоса не озвучены — слова в субтитрах, звучит неразборчивая синтетическая «речь». |
| Иконки | SVG-иконки UI, иконка приложения (SVG + PNG 180/512) | `src/ui/icons.tsx`, `public/` | PNG отрендерены из SVG |
| Шрифты | системные (serif/sans/mono) | CSS | без загрузки |

Папки `public/assets/{audio,textures,models,images}` зарезервированы под будущие записанные/смоделированные ресурсы.
