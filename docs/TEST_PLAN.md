# План тестирования

## Автоматические проверки
| Набор | Команда | Что проверяет |
|---|---|---|
| Типы | `npm run typecheck` | строгий TypeScript по всему проекту |
| Модульные (Vitest, 27 тестов) | `npm test` | коллизии; граф диалога у двери (все ссылки, обе развязки, условная реплика «вы же умерли»); распространение звука через двери/стены; режиссёр (однократность, стадии, `wait`, восстановление из сохранения, `since`); сохранения (полный круг, чужая версия, битые данные, без хранилища); изменения «за спиной»; целостность контента (уникальные id, описание каждого фрагмента) |
| Сборка | `npx vite build` | production-бандл |
| Прохождение (Playwright, Chromium) | `node tests/e2e/playthrough.mjs` | полная глава до финала «Закрытая дверь» и до «Открытая дверь» (ускорение ×6, действия через отладочные хуки), сохранение → перезагрузка → «Продолжить» с проверкой мира, отсутствие ошибок в консоли |
| Мобильные (эмуляция iPhone 15 Pro) | `node tests/e2e/mobile.mjs` | реальные touch-события: джойстик двигает, свайп поворачивает (одновременно), подсказка и кнопка действия, телефон (переписка, ответ «Не доставлено», фото), пауза, портретный режим и подсказка поворота, отсутствие горизонтальной прокрутки |

Последний прогон (3 ноября 2026, в облачном контейнере): все наборы зелёные — см. `DEVELOPMENT_LOG.md`.

## Ограничения автоматики
- WebGL в контейнере — программный (SwiftShader): FPS там не показателен.
- Реальный Safari/WebKit на iPhone не запускался: нет устройства. Звук автоматически не прослушивается.

## Ручная проверка на iPhone (чек-лист)
1. Открыть ссылку в Safari, «Начать». Звук дождя появился сразу? (если нет — выключить беззвучный режим).
2. Горизонтально: джойстик плавный, обзор свайпом без рывков, ничего не уходит под «чёлку»/Dynamic Island.
3. Вертикально: подсказка поворота, затем игра работает.
4. Включить «Показывать FPS» в настройках: в квартире ≥30 FPS на «Средней». При просадке игра сама понижает качество.
5. Свернуть Safari на 10 с и вернуться — пауза, после «Продолжить» звук возвращается.
6. Пройти до 03:17: вибрация/баннер SMS, телефон открывается, ответ «Не доставлено», запись в диктофоне играет с расшифровкой.
7. Зеркало в ванной показывает отражение (на «Низкой» — тёмное стекло).
8. Обе концовки; после финала «Продолжить» неактивно, «Начать» работает.
9. Пауза → «Сохранить», закрыть вкладку, открыть снова → «Продолжить».
10. Добавить на экран «Домой» и запустить в полноэкранном режиме.
11. 20+ минут игры: нет перегрева/вылета вкладки (следить за FPS).
