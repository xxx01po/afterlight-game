# FOMA ANIMATION STUDIO

Производственная база авторского хоррор-канала с постоянным героем — **Фомой**.
Канал: YouTube, русский язык, кинематографичная мультяшная 3D-анимация, 15–40 мин на выпуск.

> Студия живёт в подпапке `foma-studio/`, чтобы не мешать игре AFTERLIGHT в корне репозитория.
> Когда начнётся настоящее производство, её лучше перенести в отдельный репозиторий (см. `docs/02_architecture.md`, раздел «Хранение»).

## Что блокирует переход к генерации (нужно от тебя)

1. **Утверждённый дизайн Фомы — изображения.** В задаче сказано «утверждённый дизайн», но ни одного файла не приложено. Без картинки-эталона система консистентности не работает. Положи 1–5 изображений в `foma-studio/bible/reference/`.
2. **Референсы «За Чертом».** Тоже не приложены. Пришли ссылки на 3–5 роликов — разберу визуальный язык (через vidIQ-анализ видео это 25 кредитов за ролик, или вручную по кадрам).
3. **Доступ к генерации видео.** В этом контейнере нет GPU и нет оплаченного видеосервиса (детали в аудите). Минимум для теста — подписка Kling (Pro) **или** API-ключ fal.ai / Replicate в секретах окружения.
4. **Голос.** Для продакшена — ElevenLabs (Creator) или self-hosted Fish-Speech/CosyVoice. Бесплатный черновой голос уже работает (см. `production/ep000_test/audio/`).

## Быстрый старт

```bash
cd foma-studio
pip install edge-tts                      # черновой голос (только для аниматиков!)
python3 tools/scratch_voice.py production/ep000_test/dialogue.csv production/ep000_test/audio/scratch
python3 tools/build_animatic.py production/ep000_test/shotlist.csv production/ep000_test/animatic/T01_animatic.mp4
```
