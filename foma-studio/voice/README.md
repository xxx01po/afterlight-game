# Голос Фомы

**Утверждённый кандидат:** `FOMA_VOICE_V1` — оригинальный синтетический голос.
Мастер-эталон: [`master/foma_voice_master.wav`](master/foma_voice_master.wav), SHA-256 `dbe081a8e0cffaf7…`.
Финальное утверждение — за автором канала после прослушивания (я оценивал по замерам, не на слух).

## 1. Как устроен голос (два шага)

```
[Qwen3-TTS VoiceDesign]  текстовое описание → оригинальный голос (не клон человека)
          │  seed 1234, fp32
          ▼
foma_voice_design_raw.wav ──rubberband −2 полутона, форманты сохранены──▶ foma_voice_master.wav   ← «Voice ID» Фомы
                                                                               │
[Chatterbox Multilingual]  клонирует мастер + управляет эмоцией (exaggeration) ◀┘
          ▼
реплики серий (каждая с записанным seed)
```

Почему так: VoiceDesign умеет **придумать** голос по описанию, но при генерации каждой эмоции заново голос «плывёт» (сходство падает до 0,55). Поэтому придуманный голос один раз фиксируется в файле-эталоне, а дальше все серии клонируются из этого файла. Эталон — это и есть «Voice ID», только хранится он у нас в репозитории, а не на чужом сервере.

### Шаг 2 — мастер
```bash
ffmpeg -i foma_voice_design_raw.wav -af "rubberband=pitch=0.8909:formant=preserved:pitchq=quality" -ar 24000 foma_voice_master.wav
```
−2 полутона: исходный дизайн звучал выше целевого «средне-низкого» регистра.

### Шаг 3 — реплики (каждая серия)

| Водяной знак | Perth (неслышимый, встроен автоматически) — маркирует речь как синтетическую |

**Пресеты эмоций** (`exaggeration` / `cfg_weight`):

| Эмоция | exaggeration | cfg_weight | Комментарий |
|---|---|---|---|
| спокойно | 0.45 | 0.5 | |
| шутка / ирония | 0.6 | 0.45–0.5 | |
| испуг | 0.7–0.8 | 0.35–0.4 | голос поднимается, сбивчивое дыхание |
| шёпот | 0.5–0.6 | 0.3 | настоящий шёпот (20% вокализованных кадров) |
| паника | 1.0 | 0.3 | темп медленнее нужного → ускорять ×1.1–1.15 в монтаже или писать короче |

**Пост-обработка (фирменная «маска»):** `tools/mix_t01.py` → `FX["mask"]` — лёгкая «коробочность» ~900 Гц, срез низа/верха, компрессия, ранние отражения помещения.

```bash
export CHATTERBOX_DIR=/path/to/chatterbox_weights HF_HUB_OFFLINE=1
python voice/engines/engine_chatterbox.py <реплики.yaml> <out_dir> --ref voice/master/foma_voice_master.wav --seed 1234
python voice/engines/engine_chatterbox.py <реплики.yaml> <out_dir> --ref ... --seed 7 --only L02 --suffix _s7   # перегенерация дубля
```

## 3. Как сравнивали (4 движка, 2 раунда)

Один и тот же текст из 5 эмоций ([`test_script.yaml`](test_script.yaml)): обычная речь, шутка, испуг, шёпот, паника. Метрики ([`evaluate.py`](evaluate.py)):
- **CER** — Whisper распознаёт речь обратно, считаем ошибки по символам (разборчивость, правильность слов);
- **spk_sim** — сходство «отпечатка голоса» каждой эмоции с эталоном (стабильность персонажа);
- **F0** — высота голоса (цель «средне-низкий молодой мужской»: ~100–150 Гц в спокойной речи);
- **voiced** — доля вокализованных кадров (в шёпоте должно быть мало);
- разброс темпа / громкости / высоты между эмоциями (насколько «живо» играет).

## 4. Что проверить на слух (я этого сделать не могу)

1. Нет ли иностранного акцента или «машинности» в ударениях (Whisper их не ловит, если слово узнаваемо).
2. Хватает ли хрипотцы. HNR ~3–4 дБ говорит о шумности/придыхании, но «хрипотца» — субъективное качество.
3. Звучит ли он на 18–22 года, а не старше или младше.
4. Харизма и дерзость — это актёрская подача, её задают в основном текст и режиссура реплик.

Если голос не нравится, меняем **только мастер** (другой seed в шаге 1 или другое описание). Весь остальной конвейер остаётся тем же.
