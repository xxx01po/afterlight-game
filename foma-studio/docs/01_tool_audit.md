## 9. Ограничения, о которых надо знать честно

1. **Я не могу сам зарегистрироваться и оплатить сервис.** Подписку оформляешь ты. Если нужен «автопилот» — добавь API-ключ в секреты окружения (меню окружения в заголовке сессии → Edit → Network secrets/переменные). Я буду читать, например, `FAL_KEY`, `ELEVENLABS_API_KEY`, `KLING_ACCESS_KEY`/`KLING_SECRET_KEY`, `RUNPOD_API_KEY`. Никогда не вставляй ключи в чат.
2. **Я не вижу видео как зритель.** Проверку кадров делаю по извлечённым стоп-кадрам (ffmpeg → изображения → визуальный осмотр). Финальное «ощущение» ритма и страха — за тобой.
3. **Без GPU** open-source модели здесь не запускаются; нужен облачный GPU.
4. **Цены** взяты из вторичных обзоров 2026 года, которые расходятся между собой. Сверять на официальных страницах.
