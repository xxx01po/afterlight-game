# QC: пакет эталонов, попытка 2 (Gemini, правки по QC попытки 1)

| Пункт | front a | front b | ¾ |
|---|---|---|---|
| Волосы чёрные | ✅ | ✅ | ✅ |
| Маска: серая + чёрный клин сверху вниз до острия | ✅ (клин по центру; на листе чуть правее центра — допустимо) | ✅ то же | ✅ |
| Трещины | ✅ | ✅ | ✅ |
| Оба глаза светятся, миндаль | ✅ | ✅ | ✅ |
| Крест на груди | ✅ | ✅ | ✅ |
| Рюкзак, карго, светлые кроссовки | ✅ | ✅ | ✅ |
| Без логотипов | ✅ | ✅ | ⚠️ на левом кроссовке осталась бледная «галочка» |
| Белая футболка | ⚠️ лишь край у ворота — допустимо | ⚠️ то же | ⚠️ то же |

Решение: **front a — кандидат в эталон** (a и b почти одинаковы, берём a). ¾ — кандидат после удаления следа логотипа.
Осталось переделать: маска крупно, спина (из попытки 1: каштановые волосы, половина маски чёрная / белая футболка).
