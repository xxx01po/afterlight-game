# 3D-превиз (previz)

Детерминированная 3D-сцена теста T-01 «Дверь» на three.js, рендер в headless Chromium → ffmpeg.

## Зачем, если есть ИИ-видео

1. **Генерация видео сейчас недоступна** (нет GPU, нет оплаченного сервиса — см. `docs/01_tool_audit.md`). Превиз — рабочая альтернатива, чтобы проверить режиссуру, тайминг, звук и монтаж уже сейчас.
2. **Это уровень 5 системы консистентности** (`docs/03_foma_consistency.md`): 3D-манекен Фомы, геометрия которого задана кодом и не может «уплыть». Из него можно рендерить позы и ракурсы как стартовые кадры для image-to-video.
3. **Тайминг и камера переносятся 1:1** в продакшен: каждый кадр шот-листа = блок камеры в `scene.js`.

## Чем превиз НЕ является

Это не финальная картинка. Манекен собран из примитивов и передаёт **силуэт, маску, свет, движение и ракурсы**, а не художественное качество листа персонажа (`bible/reference/foma_sheet_v1.png`). Финальный стиль — через генерацию по референсам листа.

## Что сделано по утверждённому листу

| Элемент | В превизе |
|---|---|
| Маска | щит с заострённым подбородком, пепельно-серая, чёрный клин сверху вниз правее центра (для зрителя), трещины, тёмная окантовка прорезей |
| Глаза | белое свечение, миндаль с поднятыми внешними уголками; сужение и тускнение по эмоции, моргания |
| Капюшон | всегда надет, из-под него — пряди волос |
| Одежда | оверсайз-худи, карман-кенгуру, шнурки, крест на груди; широкие карго с карманами и стропами |
| Рюкзак | тактический, лямки + нагрудная стропа с пряжкой |
| Кроссовки | светлые, толстая подошва, тёмная вставка |
| Руки | человеческие, кожа |

## Запуск

```bash
cd foma-studio/previz
npm i three@0.170.0               # playwright уже установлен в среде
node render.mjs --stills ../out/stills 4,19.5,30      # отдельные кадры для проверки
node render.mjs ../out/previz.mp4 24 0 48.5            # полный рендер (~12 мин на 4 CPU)
```

`renderAt(t)` полностью определяет кадр по времени — никаких накопленных состояний, любой кадр рендерится независимо (можно параллелить по отрезкам).
