## ПОСЛЕДНЯЯ СМЕНА

Ночной охранник объекта 17 у заброшенной деревни. Дождь, лес, генератор, который нельзя глушить, и рация, которая иногда говорит твоим голосом.
Четыре зоны (охраняемый объект, лес, деревня Сосновка, НИИ «Кедр-7»), физика Rapier, ИИ на конечном автомате, система аномалий, процедурный звук, сохранения в IndexedDB, сенсорное управление.

```bash
npm install
npm run dev                                         # http://localhost:5173/smena/
npm test                                            # модульные тесты
node tests/e2e/smena-playthrough.mjs http://localhost:5173   # полное прохождение
node tests/e2e/smena-mobile.mjs http://localhost:5173        # эмуляция iPhone, мультитач
```

Управление: телефон — левая половина экрана джойстик (до упора — бег), правая — обзор, кнопки справа. Клавиатура — WASD, Shift, C, E, F, R/ЛКМ, Tab, J, Esc.

# AFTERLIGHT — Глава 1: «03:17»

Психологический хоррор от первого лица для мобильного браузера (основная платформа — iPhone / Safari).
Ночь, дождь, съёмная однушка в панельном доме. В 03:17 Владу приходит сообщение с его собственного номера:
«Влад, если ты это читаешь, значит, всё началось заново». Потом — три удара в дверь.

Это **играбельная вертикальная демоверсия**: одна глава, ~15–25 минут, два финала, сохранения.

## Что есть в демо

- Квартира (прихожая, комната, кухня, совмещённый санузел, кладовка), лестничная клетка, лифт, вход в кв. 48, двор за окном с дождём.
- Ходьба от первого лица: сенсорный «плавающий» джойстик слева, обзор свайпом справа, коллизии; клавиатура и мышь на ПК.
- Взаимодействия: двери, выключатели, шкаф, ящик стола, холодильник, телевизор, кран, чайник, домофон, глазок, записки, фотографии, ключ.
- Телефон героя: сообщения (с ответами), звонки (входящие, исходящие, история), фото, диктофон с расшифровкой, заметки.
- Диалог через дверь с выбором, влияющим на финал главы.
- «Меняющаяся реальность»: предметы меняются, только когда игрок на них не смотрит; всё спроектировано и воспроизводимо.
- Процедурный звук (Web Audio): дождь, вентиляция, трубы, холодильник, соседи, лифт, домофон, шаги по разным покрытиям, телефон; приглушение звука стенами и дверьми.
- Сохранения (LocalStorage, контрольные точки + ручное сохранение), настройки громкости и графики, автоснижение качества.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (и адрес в локальной сети для телефона)
npm run build      # typecheck + production-сборка в dist/
npm run preview    # раздать собранную версию
npm test           # модульные тесты (Vitest)
```

Браузерные проверки (нужен запущенный `npm run preview` на порту 4173 и Playwright):

```bash
node tests/e2e/playthrough.mjs   # полное прохождение обеих концовок + сохранение/загрузка
node tests/e2e/mobile.mjs        # эмуляция iPhone: джойстик, свайп, телефон, портретный режим
```

## На iPhone

1. Откройте ссылку на опубликованную версию в Safari.
2. Наденьте наушники, отключите беззвучный режим (на iOS < 17 переключатель «бесшумно» глушит Web Audio).
3. Поверните телефон горизонтально.
4. Для настоящего полноэкранного режима: «Поделиться» → «На экран „Домой“» и запускайте с иконки.
