## 5. Настройки в YouTube Studio

| Поле | Что выбрать |
|---|---|
| Аудитория | Реши честно, как для первой серии. Если «Для детей» — отключатся комментарии и колокольчик |
| Изменённый/синтетический контент | «Нет»: очевидная анимация, голоса не имитируют реальных людей. Перепроверь формулировку в Studio |
| Категория | Игры → игра **Roblox** |
| Язык | Русский |
| Субтитры | Загрузить `subtitles.srt` (Русский) |
| Лицензия | Стандартная YouTube; музыка и звуки синтезированы — Content ID не должен сработать |
| Плейлист | «Фома» (тот же, что для первой серии) |
| **Связанное видео** | **Укажи бургерную серию.** А в бургерной — эту. Зритель переходит между сериями одним нажатием |

## 6. Обложка
- **Телефон:** при загрузке — карандаш на превью → «Обложка» → `NOCT_FOMA_SCHOOL_cover.png`.
- **Если своя картинка недоступна в твоём приложении:** кадр на **0:17** (Фома с поднятой рукой «Так… всем сесть!») — тот же сюжет, что на обложке.

## 7. Загрузка (~2 минуты)
1. YouTube → «+» → «Создать Short» → «Загрузить» → `NOCT_FOMA_SCHOOL_SHORT.mp4`. Не обрезай и не добавляй звук из библиотеки — звук уже сведён.
2. Название из п.1, аудитория по п.5, обложка по п.6 → «Загрузить Short».
3. Сразу закрепи комментарий из п.4.
4. В Studio: описание, теги, «Игры → Roblox», субтитры, плейлист «Фома», связанное видео.

## 8. Через 24–48 часов
- Studio → Аналитика этого Short → «Смотрели / пролистали» и удержание.
- Провал в первые 2 с → меняй название/обложку на запасной вариант «стал ЗАВУЧЕМ».
- Провал около **0:02–0:05** (перемотка и «20 СЕКУНД НАЗАД») → флешбек затянут, можно сократить коридор.
- Сравни удержание с бургерной серией: какой формат держит лучше, такой и делать следующим.
